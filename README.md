# AASH International Website

A modern, responsive static website for AASH International / Advance Academy Safety and Health.

## Publish options
1. Netlify: drag the `aash-international-website` folder into Netlify Drop.
2. GitHub Pages: create a repository, upload all files, then enable Pages from the repository settings.
3. Any normal web hosting: upload `index.html` and the `assets` folder to `public_html`.

## Important
- Update course fees, intake dates, exact awarding-body wording and accreditation claims before publishing.
- The site deliberately avoids unsupported accreditation claims and tells visitors to confirm current programme details.
- Replace/extend course cards as new intakes become available.
